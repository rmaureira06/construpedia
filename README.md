# Construpedia

Glosario y enciclopedia de términos de construcción civil chilena, con más de 500 términos, datos curiosos y buscador.

🔗 **Sitio en vivo:** [rmaureira06.github.io/construpedia](https://rmaureira06.github.io/construpedia/)

## Contenido

* **+500 términos técnicos**, organizados en distintas categorías.
* **+90 datos curiosos** ("¿sabías que...?") sobre normativa chilena, historia de palabras técnicas y curiosidades del rubro, mostrados de forma rotativa mientras se navega.
* Buscador y navegación alfabética A-Z.

## Funcionalidades

* Página 100% estática, sin necesidad de servidor ni base de datos.
* Formulario de sugerencias y feedback, con envío directo al correo del autor.
* Botón de feedback ocultable/recuperable por el usuario.

## Seguridad del formulario de feedback

* **Formshield** (Formspree): filtro de spam con machine learning.
* **Google reCAPTCHA v2**: verificación humana mediante checkbox "No soy un robot".
* **Honeypot**: campo oculto que descarta envíos automáticos de bots.
* **Restricción de dominio**: el endpoint del formulario solo acepta envíos desde este sitio.
* Límite de 1.000 caracteres por mensaje, con contador visual.
* Ningún mensaje se publica automáticamente: todo pasa primero por revisión manual vía correo.
